# 🎁 La liste d’Ethan

Site web personnel permettant de consulter une liste de cadeaux pour Noël et l’anniversaire 2026.

## 🌐 Site

https://ethangalea1000-svg.github.io/Liste-cadeaux-ethan/

## ✨ Fonctionnalités

- Recherche et filtrage des cadeaux
- Statistiques des cadeaux
- Réservation locale dans le navigateur
- Partage de la liste
- Interface adaptée aux ordinateurs et mobiles

## ⚠️ Réservations

Les réservations utilisent actuellement `localStorage`. Elles ne sont donc pas synchronisées entre plusieurs appareils. Une base de données sera nécessaire pour une réservation réellement partagée.
