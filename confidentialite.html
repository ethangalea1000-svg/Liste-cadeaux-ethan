🔒 Confidentialité

Informations sur les données personnelles et leur utilisation sur ce site.

1. À quoi sert cette page ?

Cette page décrit, de manière adaptée à ce projet personnel, quelles informations peuvent être demandées, enregistrées ou transmises lorsque tu utilises la liste de cadeaux, les demandes d’accès, la communauté, les modules d’anniversaire ou l’extension associée.

Important : cette page est une information sur le fonctionnement actuel du projet. Elle ne constitue pas, à elle seule, une garantie de conformité juridique complète. Pour une question concernant un mineur, un parent ou un responsable légal, il est préférable de demander conseil à un adulte responsable et, si nécessaire, à un professionnel compétent.

2. Quelles données peuvent être collectées ?

  • Identité affichée : le prénom ou nom utilisé sur la liste peut être demandé pour certaines réservations, participations, idées, suggestions, messages ou publications.
  • Demande de création d’accès : le formulaire de demande peut enregistrer le nom, la relation avec Ethan, un avatar facultatif et une courte présentation facultative. La demande est enregistrée avec un statut tel que « en attente », « approuvée » ou « refusée ».
  • Code d’accès : lorsqu’une demande est approuvée ou qu’un accès est créé directement, un code d’accès peut être associé à la personne ou à son libellé d’accès afin d’autoriser l’entrée dans la liste privée.
  • Réservations : le cadeau réservé et le prénom associé peuvent être conservés.
  • Participations financières annoncées : le cadeau ou la cagnotte concerné, le prénom, le montant et, selon le formulaire, un message peuvent être conservés.
  • Suggestions et idées : le contenu envoyé, un nom, un lien et un message peuvent être enregistrés afin de permettre leur validation ou leur gestion.
  • Communauté : les publications peuvent contenir un prénom, un message, un lien et jusqu’à plusieurs pièces jointes selon les limites du site. Les réactions peuvent également être enregistrées.
  • Messages privés : le prénom et le contenu du message envoyé à Ethan peuvent être enregistrés. Ces messages ne sont pas affichés publiquement.
  • Anniversaire : les modules peuvent enregistrer des interactions liées au quiz, au vote, aux défis, au mur de messages, à la galerie, aux souvenirs ou aux autres fonctionnalités d’anniversaire.
  • Données techniques : certaines informations nécessaires au fonctionnement du navigateur et du site peuvent être stockées localement, notamment des préférences ou la position de défilement de la page.

3. Comment fonctionnent les codes d’accès ?

Le catalogue privé n’est chargé qu’après vérification d’un code d’accès actif. Un code peut être partagé avec une personne invitée et peut être désactivé depuis l’administration.

Lorsqu’une demande d’accès est approuvée, l’administration peut créer un code et un lien de partage associés. La demande elle-même n’accorde pas automatiquement l’accès.

Le site applique également un mécanisme de limitation des tentatives répétées afin de ralentir les essais automatisés ou abusifs.

4. Pourquoi ces données sont-elles utilisées ?

  • gérer les réservations et les participations aux cadeaux ;
  • gérer les cagnottes et leur validation ;
  • recevoir puis modérer les suggestions, idées et publications ;
  • gérer les demandes de création d’accès ;
  • faire fonctionner la communauté, les fichiers et les messages privés ;
  • faire fonctionner les modules de l’anniversaire 2026 et la Murder Party Hydra ;
  • diagnostiquer certains problèmes techniques et, lorsqu’elle est activée avec consentement, mesurer l’utilisation du site via la télémétrie de l’extension.

5. Qui peut voir les informations ?

Les informations ne sont pas toutes publiques.

  • Les données de gestion des accès, demandes d’accès, cagnottes, suggestions et réglages sont destinées à l’administration du site.
  • Les réservations et informations du catalogue privé sont accessibles aux visiteurs disposant d’un accès autorisé.
  • Les publications communautaires validées ou affichées par le site peuvent être visibles par d’autres personnes ayant accès à la communauté.
  • Les messages privés ne sont pas affichés aux visiteurs ordinaires.
  • Pour la Murder Party Hydra, le fonctionnement prévu est qu’un invité autorisé ne reçoive que le dossier correspondant à son accès, tandis que l’administration gère les dossiers complets.
  • Les données techniques stockées dans Supabase peuvent être accessibles aux fonctions d’administration prévues par le projet.

6. Services utilisés

Le site repose principalement sur :

  • GitHub Pages pour publier les pages web ;
  • Supabase pour la base de données, les fonctions SQL/RPC, certaines protections serveur et le stockage de fichiers ;
  • des services externes de recherche ou de vente ouverts au travers de liens ou de résultats affichés par le site.

Lorsqu’un lien ouvre un service externe, l’utilisation de ce service est ensuite soumise à sa propre politique de confidentialité et à ses propres conditions.

7. Extension « Mes données — Liste d’Ethan »

L’extension de navigateur associée au projet existe séparément du site public. Sa version actuelle est la 1.2.0.

Après consentement explicite, elle peut transmettre à Supabase des événements liés au site, par exemple :

  • pages consultées ;
  • clics ;
  • titre de la page ;
  • langue et fuseau horaire ;
  • taille de l’écran et de la fenêtre ;
  • thème clair / sombre ;
  • état en ligne ;
  • informations de connexion disponibles au navigateur ;
  • événements de visibilité, redimensionnement et changement de réseau.

L’extension est conçue pour ne pas enregistrer les mots de passe, les codes d’accès à la liste, le contenu des champs de formulaire ou les messages privés.

L’identifiant utilisé pour regrouper les événements de télémétrie est pseudonyme et lié à l’installation de l’extension.

La préférence de « cookies » affichée par l’extension correspond à ce choix de télémétrie : elle ne sert pas à installer de la publicité personnalisée.

8. Cookies et stockage local

Le site utilise des mécanismes standards du navigateur lorsque cela est nécessaire à son fonctionnement. Il peut notamment utiliser le stockage de session pour conserver temporairement certains états de navigation ou de connexion.

Le fonctionnement actuel ne décrit pas de revente de données ni de publicité personnalisée intégrée à la liste.

Si un nouveau service externe, cookie ou outil d’analyse est ajouté plus tard, cette page devra être mise à jour pour le décrire.

9. Publications et fichiers

Avant de publier un message, un lien ou un fichier dans la communauté, vérifie qu’il ne contient pas d’adresse, numéro de téléphone, photo, document scolaire, mot de passe ou autre information privée que tu ne souhaites pas partager.

Les fichiers communautaires sont gérés via le stockage Supabase associé au projet et peuvent être liés à une publication.

10. Sécurité

Le projet utilise HTTPS pour ses pages publiées, les mécanismes de sécurité de Supabase, la Row Level Security et des fonctions SQL pour certaines opérations sensibles.

La sécurité informatique ne peut toutefois jamais être garantie à 100 %. Ne publie donc jamais un mot de passe, une clé secrète ou une donnée très sensible dans la communauté ou dans un formulaire qui n’est pas prévu pour cela.

À retenir : un lien ou un code d’accès doit être considéré comme une information privée. Ne le partage pas avec une personne qui ne doit pas accéder à la liste.

11. Mineurs

Le site peut être utilisé par des mineurs. Il est recommandé de ne publier que les informations strictement nécessaires et de demander l’accord d’un parent ou responsable légal lorsqu’une publication contient une information personnelle ou un fichier concernant un mineur.

Une demande concernant les données d’un mineur peut également être formulée par son parent ou responsable légal, selon la situation et les règles applicables.

12. Suppression et modification

Le site prévoit différentes fonctions de suppression ou de modification, parfois avec vérification du prénom utilisé, pour certaines réservations, participations, idées, suggestions ou publications.

Les informations qui ne peuvent pas être modifiées directement depuis l’interface peuvent faire l’objet d’une demande adressée au responsable du site avec suffisamment d’éléments pour identifier la donnée concernée.

Une demande de suppression ne doit pas être utilisée pour contourner les contrôles de sécurité ou supprimer les données d’une autre personne.

13. Conservation

Il n’existe pas actuellement une durée unique de conservation documentée pour toutes les catégories de données du projet. Selon leur nature, certaines informations peuvent rester dans Supabase ou dans les historiques techniques jusqu’à leur suppression, leur archivage ou leur remplacement.

Lorsqu’une fonctionnalité est retirée ou modifiée, les données associées ne sont pas nécessairement supprimées automatiquement.

14. Vos droits

Selon la situation et les règles applicables, une personne peut notamment disposer de droits concernant l’accès, la rectification, l’effacement, la limitation du traitement ou l’opposition à certains traitements de ses données.

Pour une demande concernant les données utilisées par ce projet, contacte le responsable du site avec les informations permettant d’identifier la donnée concernée. En France, la CNIL fournit également des informations générales sur les droits relatifs aux données personnelles.
