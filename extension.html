À quoi sert-elle ?

Cette extension enregistre localement les actions effectuées sur le site de la liste d’Ethan : visites de pages et clics sur les boutons/liens. Elle permet ensuite d’exporter ces événements en JSON.

Confidentialité : elle ne surveille pas Google, les autres sites, les mots de passe, les messages privés ou toute l’activité générale d’une personne.

Installer dans Chrome / Edge

1. Télécharge ou clone le dépôt GitHub de la liste.
2. Ouvre chrome://extensions.
3. Active Mode développeur.
4. Clique sur Charger l’extension non empaquetée.
5. Sélectionne le dossier extension du dépôt.
6. Épingle l’extension avec l’icône puzzle.
